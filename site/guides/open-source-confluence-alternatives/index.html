What are the best open-source Confluence alternatives?

Seven open-source Confluence alternatives compared on licence, paid tiers and Confluence import: Turtle, Docmost, BookStack, XWiki, Wiki.js, Outline, DokuWiki.

Try the demo Ask Jérémie by email
Jérémie ConstantBuilds Turtle at novalutions. Updated 27 November 2026.

Short answer

We build Turtle, so this list is not neutral. Turtle comes first because it is our own product, not because it won a test. The other six follow the order we were asked to cover them in. For each one we checked the licence, what sits behind a paid tier, the stack you have to run and how you get Confluence content in.

If you want a fully open-source wiki with a built-in Confluence importer and no paid edition, look at Turtle, and at XWiki if you need deep permissions. If you need SSO, page-level permissions and a mature product today, Docmost and Outline cover that in their paid tiers. Note that Outline is source-available, not open source.

Why teams leave Confluence

The main trigger is the end of Confluence Data Center. Atlassian has announced three dates. New customers could no longer buy Data Center subscriptions after 30 March 2026. Existing customers lose the option to buy new subscriptions and expansions after 30 March 2028.

On 28 March 2029, Data Center reaches end of life. Subscriptions and Marketplace apps expire and instances become read-only. Atlassian points Data Center customers to its Cloud.

If you run Confluence on your own servers for data control, cost or compliance reasons, that leaves two paths: move to Atlassian Cloud or move to another tool. This guide covers the second path. For the full timeline, read Confluence Data Center end of life.

The seven tools

1. Turtle

Licence: AGPL-3.0. No paid edition, no enterprise edition, no CLA.

Turtle is a self-hosted wiki where people and AI agents write documentation together. It ships as one Rust binary with the web app built in and stores data in SQLite plus a data directory, so you run no database server. Live editing, versions, Markdown export and a built-in MCP server are included. Turtle imports Confluence spaces from Data Center and Cloud, and you can try it in the demo. Export the space as CSV or XML with attachments. The tree, attachments, page links, labels and mentions come across, some macros only approximately, and every import leaves an Import report and can be undone. Turtle is early. Per-page permissions, guests, groups, SSO, comments and templates are on the roadmap, not in the product. The data format may change before 1.0.

2. Docmost

Licence: AGPL-3.0 for the core. Files in the ee folders fall under the Docmost Enterprise licence.

Docmost offers real-time editing, spaces, comments, page history and diagrams. The free Community edition covers the core. SSO, page-level permissions, AI and MCP, and the Confluence importer sit in the Business plan at $6 per seat per month with a 10-seat minimum. The importer reads a Confluence HTML export. You run the app with PostgreSQL and Redis. Turtle vs Docmost

3. BookStack

Licence: MIT. No paid edition. Support plans and donations fund the project.

BookStack organises content into shelves, books, chapters and pages, which suits manuals and handbooks. It runs on PHP 8.2 or newer with MySQL 8.0 or MariaDB 10.6 or newer. The project says it has no automated way to migrate content from Confluence yet and suggests its REST API for scripted moves. Development is now managed on Codeberg. Turtle vs BookStack

4. XWiki

Licence: LGPL-2.1. Paid Pro apps, support plans and cloud hosting from XWiki SAS.

XWiki is a Java platform with a long history and a large extension catalogue. A free Confluence XML filter imports exported spaces, with limits on macros and long page names. The paid Confluence Migration Toolkit goes further: it can carry over space permissions, page restrictions, page history and labels. It is included from the Business support plan or sold as part of the toolkit. Expect a heavier setup than the other tools here.

5. Wiki.js

Licence: AGPL-3.0. No paid edition. Funded through sponsors.

Wiki.js is a Node.js wiki with a Markdown focus. The project site lists PostgreSQL 17 or newer for version 3. On GitHub, the 3.x releases are still labelled beta and not for production use, while 2.x remains the stable line. We found no documented Confluence importer. Plan to convert exports yourself or through a third-party tool.

6. Outline

Licence: Business Source License 1.1. This is source-available, not open source.

Outline's licence lets you self-host for your own team. It forbids offering Outline to third parties as a commercial document service. Each version converts to Apache 2.0 at the latest four years after release. Self-hosting needs PostgreSQL and Redis, and Outline has no native email and password login. The Confluence importer, SAML and guests are in the self-hosted Business plan ($4 per user per month, 10 users minimum) and Enterprise. Turtle vs Outline

7. DokuWiki

Licence: GPL-2.0. No paid edition.

DokuWiki is a PHP wiki that stores pages as plain text files and needs no database. That makes backups and moves simple. It uses its own wiki syntax and a classic interface. Confluence migration depends on a community script that converts a Confluence HTML export with pandoc. Its author calls it a personal tool, and most macros are lost because they are not in the HTML export.

What you give up

Every tool on this list does less than Confluence in some areas. Check these three before you commit.

Macros. Confluence pages often depend on macros for status labels, page includes, Jira issues and dynamic lists. Outline's importer skips macros, comments and authorship. Docmost lists formatting, page tree, links, images and draw.io diagrams as preserved. XWiki's paid migrator converts macros and can keep Confluence-specific ones with a prefix. Turtle will never support content that cannot be expressed in Markdown, so macros, whiteboards and databases stay out.

Marketplace. Confluence has a large app marketplace. XWiki has about 900 community extensions. The others have integrations or APIs but no marketplace on that scale. Turtle has no plugin marketplace and none is planned. It offers an HTTP API and an MCP server instead.

Deep permissions. Confluence supports space permissions, page restrictions and groups. XWiki's migrator can bring those across. Docmost and Outline put page-level permissions or SAML behind paid tiers. Turtle today has roles per Area (Read, Write, Admin) and workspace admins. Per-page permissions, guests and groups are planned for 0.4 and 0.5.

For step-by-step planning, read How to migrate from Confluence.

Frequently asked

Is Outline open source?

No. Outline uses the Business Source License 1.1, which restricts commercial use as a document service for third parties. Each version becomes Apache 2.0 later. You can read the code and self-host it for your own team.

Which tools import Confluence content without a paid plan?

Turtle imports Data Center and Cloud spaces with no paid tier. XWiki has a free XML filter with fewer conversion options than its paid toolkit. DokuWiki has a community script. Docmost and Outline restrict their importers to paid plans. BookStack and Wiki.js document no importer.

What happens to Confluence Data Center on 28 March 2029?

Subscriptions and Marketplace apps expire and instances become read-only, according to Atlassian. Security updates for critical issues run until that date.

Can I self-host a Confluence alternative without a database server?

Yes. Turtle uses SQLite in a single binary. DokuWiki stores pages as text files. Docmost and Outline need PostgreSQL and Redis. BookStack needs MySQL or MariaDB, and Wiki.js 3 needs PostgreSQL.

Which tools let AI agents read and write the wiki?

Turtle has a built-in MCP server. Agents connect over OAuth and never get more access than the member who connected them. Docmost includes AI and MCP in its Business plan. Outline's cloud plans include an MCP server. See A wiki for AI agents with MCP.

Is Turtle ready for production?

Turtle is in an early phase. A load test with 500 concurrent writers is documented in the repository. Until 1.0, the data format and API can change between releases, and an external security review is planned for 1.0. Back up by stopping Turtle and copying the data directory.
