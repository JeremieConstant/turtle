An open-source Outline alternative you can run as one binary

Outline is a fast, polished team wiki. Turtle is younger and does less. It is AGPL licensed, uses email and password sign-in and runs as one binary with SQLite.

Try the demo Ask Jérémie by email

Short answer: is Turtle a good Outline alternative?

Yes, if you want an open-source licence and a wiki you can host without PostgreSQL, Redis or an identity provider.

No, if you need comments, groups, guests or SSO today. Outline has them. Turtle is early, and its data format and API can change before 1.0.

At a glance

Licence
Turtle is AGPL-3.0 with no paid edition. Outline is BSL 1.1, which is source-available, not open source.
Hosting
Turtle is one binary with SQLite. Outline needs PostgreSQL and Redis.
AI access
Both ship an MCP server at /mcp with OAuth.
Pricing
Turtle is free to self-host, a hosted version is on a waitlist. Outline Cloud starts at $3 per user per month.

Why teams choose Turtle

A licence without conditions on use

Outline's BSL allows production use but excludes offering it as a commercial document service. Turtle's AGPL-3.0 has no such clause, no paid edition and no contributor licence agreement.

Sign in with email and password

Outline does not store passwords. Sign-in goes through an identity provider, a passkey or an emailed link that needs SMTP. In Turtle, members sign in with email and password. No Google, Microsoft or OIDC server required.

One binary instead of a stack

Self-hosted Outline needs PostgreSQL and Redis, with storage on disk or S3. Turtle keeps everything in SQLite plus a data directory. Start it with docker compose up -d. To back up, stop Turtle and copy the data directory.

Both tools offer MCP. In Turtle, an agent never has more access than the member who connected it, and edits appear as, for example, "Demo Member via Claude". You can limit a connection to reading or single areas.

Moving from Outline to Turtle

Outline exports collections as Markdown, and Turtle imports Markdown into an area. Check links, images and nesting afterwards.

When Outline is the better choice

Pick Outline if your team relies on comments, groups, guests or SAML. It is mature, available in 17 languages and has more than 20 integrations. Its Business plan adds AI question answering and an audit log. If you want a hosted wiki today, Outline Cloud is ready and Turtle's is not.

Turtle vs Outline, answered

Is Outline open source?

No. It uses the Business Source License 1.1, and each release becomes Apache 2.0 after its change date.

Can I self-host Outline without SSO?

Outline offers emailed sign-in links with SMTP, and passkeys, but no passwords.

Does Turtle have comments like Outline?

Not yet. Comments, backlinks and templates are planned for version 0.6.

Can AI agents edit both wikis?

Yes, both include an MCP server with OAuth. Turtle admins can switch AI connections off workspace-wide.
