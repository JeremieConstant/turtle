A self-hosted Confluence alternative for teams and their AI agents

Confluence is a mature wiki with deep permissions, inline comments and a large app marketplace. Turtle is younger: an open source wiki on your own server, where people and AI agents write docs together.

Short answer: is Turtle a good Confluence alternative?

Yes, if you want a wiki you fully control. Turtle is AGPL-3.0, runs as one binary with SQLite, and can import spaces from Confluence Data Center and Cloud.

It is not a good fit yet if you rely on page-level restrictions, comments, SSO or Marketplace apps. Turtle is in an early phase, and the data format and API may change before 1.0.

Why teams choose Turtle

You keep the wiki and the data

Turtle is one binary. Data lives in SQLite plus an attachments folder, with no database server or external services. Backup means copying that folder.

You start it with docker compose up -d or a prebuilt binary for Linux or macOS.

AI agents work under your rules

Turtle has a built-in MCP server. Claude and other MCP clients connect through OAuth. An agent never gets more access than the member who connected it, and its edits appear as, for example, "Demo Member via Claude".

You can limit an agent to reading or to specific areas. Rovo, by contrast, needs a paid Confluence Cloud plan and counts usage in credits.

Everything is Markdown

Every page reads and writes as Markdown. Export an area as a Markdown ZIP with attachments, or as PDF. Editing is live, and versions can be restored.

Moving from Confluence

Turtle imports spaces from Confluence Data Center and from Confluence Cloud. The importer is part of release 0.3, "Moving in", which is out, and you can try the import in the demo.

Pages and folders keep their tree, with attachments, links between pages, labels and mentions; some macros come across only approximately, and every import leaves an Import report and can be undone.

Timing matters on Data Center. Atlassian stopped selling it to new customers on 30 March 2026. Existing customers can buy or expand until 30 March 2028. On 28 March 2029 it reaches end of life and becomes read-only. Server support already ended on 15 February 2024. See the Confluence Data Center end-of-life guide and the migration guide.

When Confluence is the better choice

Confluence wins today on macros and Marketplace apps, which Turtle will not add because it only stores what Markdown can express. It also has page and inline comments (Turtle: planned for 0.6), page-level permissions (0.4) and SSO through Atlassian Guard (OIDC planned for 0.5).

Pick Confluence if you need these now, want a vendor-run cloud with an uptime SLA, or rely on Jira and Rovo.

Turtle vs Confluence, answered

Is Turtle really open source?

Yes. Turtle is AGPL-3.0 with no paid edition and no CLA. All features are in the public repository.

Can I still self-host Confluence?

Only on Data Center, and only until 28 March 2029. New customers cannot buy it since 30 March 2026.

Does Turtle have AI features like Rovo?

Turtle ships no AI model of its own. Its built-in MCP server lets you connect the AI client you already use, with the connecting member's permissions.

Is Turtle ready for production?

Not fully. Until 1.0, the data format and API may change. A load test with 500 concurrent writers is documented in the repository. Stability commitments and an external security review are planned for 1.0.
