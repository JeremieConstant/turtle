A Docmost alternative with no enterprise edition

Docmost is a mature open source wiki with diagrams, comments and a large community. Turtle is younger and smaller. It keeps every feature in the AGPL repository, runs as one binary on SQLite, and gives every user a built-in MCP server.

Short answer: is Turtle a good Docmost alternative?

Yes, if you want an open source wiki without an enterprise edition. In Docmost, AI, MCP, SSO, API keys, page-level permissions and the Confluence importer need a Business or Enterprise licence. In Turtle there is nothing to unlock.

No, if you need comments, diagrams, groups, page-level permissions or SSO today. Docmost has them, and Turtle is still before 1.0.

Licence
Turtle is AGPL-3.0 with no paid edition and no CLA. Docmost core is AGPL-3.0, with enterprise code under a separate commercial licence.
Hosting
Turtle is one binary with SQLite. Docmost runs as an app container plus PostgreSQL and Redis.
AI access
Turtle includes an MCP server for every member. Docmost's MCP and AI features need a Business or Enterprise licence.
Pricing
Turtle is free to self-host, and a hosted version has a waitlist. Docmost Community is free, Business is $6 per seat per month with a 10-seat minimum, and Enterprise is quoted by sales.

Why teams choose Turtle

No edition line to plan around

Turtle has one edition. Roles per area, export, the HTTP API and the MCP server all ship in the same AGPL code. No feature sits behind a licence key.

One binary instead of three services

Turtle stores everything in SQLite plus a data folder. Start it with docker compose up -d or a ready-made binary. A backup means stopping Turtle and copying one directory. Docmost's compose file runs the app, PostgreSQL 18 and Redis 8, which means more to operate.

Agents work with the same rights as people

Any member can connect Claude or another MCP client to <your address>/mcp over OAuth. An agent never gets more access than the member who connected it, and its edits show up under that member's name. You can limit it to reading or single areas. Read more in the guide to a wiki for AI agents.

Moving from Docmost to Turtle

Docmost exports Markdown and HTML. Turtle imports Markdown into an area. Diagrams and comments have no counterpart in Turtle today. If you are coming from Confluence instead, see how to migrate from Confluence.

When Docmost is the better choice

Choose Docmost if your team lives in comments, draws diagrams inside pages, or needs groups and page-level permissions now. Its paid editions add databases (Bases), templates and integrations such as Jira and Microsoft 365. If you need SSO, SCIM or audit logs and can pay for a licence, Docmost covers that today. It is the more mature product with a larger community. Turtle is in an early phase, and its data format and API may change between releases until 1.0.

Turtle vs Docmost, answered

Is Docmost fully open source?

The core is AGPL-3.0. Enterprise code is under a separate commercial licence and needs a licence key. Turtle has no such split.

Does Turtle have comments and diagrams like Docmost?

Not yet. Comments are planned for 0.6. Diagrams are not planned, because Turtle only keeps content that fits in Markdown.

Can I use MCP with Docmost for free?

No. Docmost's MCP page says a Business or Enterprise licence is required. In Turtle, MCP is built in for every member at no cost.

Is there a hosted version of either?

Docmost mentions a cloud version at app.docmost.com. A hosted Turtle is announced with a waitlist, without price or date.
