Turtle compared with the wikis you know

These pages compare Turtle honestly, and each has a section on when the other tool is the better choice. They are written by the people who build Turtle.

  • Turtle vs ConfluenceTurtle is a self-hosted wiki you control, and it imports Confluence spaces.
  • Turtle vs NotionTurtle is a focused Markdown wiki, not an all-in-one workspace.
  • Turtle vs DocmostTurtle has no enterprise edition, so every feature is in the AGPL repository.
  • Turtle vs OutlineTurtle runs as one binary with SQLite and uses email and password sign-in.
  • Turtle vs BookStackTurtle adds live co-editing, a free page tree and a built-in MCP server.
