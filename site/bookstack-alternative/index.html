A BookStack alternative with live editing and AI agents built in

BookStack is a mature, MIT-licensed wiki with SSO, fine-grained permissions and page comments. Turtle is younger and does less in those areas today. It focuses on live co-editing, a free page tree and a built-in MCP server for AI agents.

Short answer: is Turtle a good BookStack alternative?

Yes, if your team writes pages together, wants a structure without fixed levels, or wants AI agents such as Claude to work in the wiki.

Not yet, if you need SAML, OIDC or LDAP login, page-level permissions or comments. BookStack has all three. Turtle plans them for versions 0.4 to 0.6, and its data format and API can change until 1.0.

Why teams choose Turtle

Write on the same page at the same time

If two people open the same page in BookStack, it warns them not to overwrite each other's updates. In Turtle, everyone on a page sees the others' changes instantly, and the page saves itself. You can run a meeting in one document.

Structure that follows your content

BookStack gives you four levels: shelves, books, chapters and pages. That suits handbooks, but gets tight when a topic needs more than one chapter level. Turtle uses areas with a free tree of folders and pages. Links stay intact when you rename or move pages.

AI agents as first-class members

Turtle has a built-in MCP server at <your-address>/mcp. Claude and other MCP clients connect through OAuth. An agent never gets more access than the member who connected it, and its edits show as, for example, "Demo Member via Claude". You can limit an agent to reading or to single areas.

BookStack has a REST API. Community projects build MCP servers on it, but none ships with BookStack.

Moving from BookStack to Turtle

BookStack exports books, chapters and pages as Markdown, and Turtle imports Markdown. Pages from BookStack's WYSIWYG editor can still contain some HTML after export, so check them after the move.

Turtle runs as one binary or with docker compose up -d. To back up, stop Turtle and copy the data directory.

When BookStack is the better choice

  • You need single sign-on through SAML 2.0, OIDC or LDAP now, or MFA enforced per role.
  • You need permissions on individual books, chapters or pages.
  • Your reviews depend on comments, inline comments and mentions.
  • You want page templates, drawings and a long release history.
  • You prefer the MIT licence.

Turtle vs BookStack, answered

Is Turtle open source like BookStack?

Yes. Turtle is AGPL-3.0, BookStack is MIT. Both are free to self-host. Under AGPL, if you offer a modified Turtle over a network, you share those changes.

Does BookStack support real-time collaborative editing?

BookStack does not list live co-editing among its features. It shows a warning when another user has started editing the same page. Turtle is built around live co-editing.

Does Turtle support SSO like BookStack?

Not yet. OIDC/SSO and groups are planned for version 0.5. Until then, you invite members by email through your SMTP server.

Can I connect Claude to BookStack?

Not out of the box. You can use BookStack's REST API or a community MCP server. Turtle ships its MCP server in the same binary.
