Turtle 0.2.0 is the version for its first public showing: Markdown can now come in as well as go out, Turtle protects its sign-in on its own, and every Release ships ready-built binaries. It is still a preview: until 1.0, the data format and the API may change between versions.

## New

- **Import a ZIP of Markdown files.** Someone with Write can import an Export, or any folder of Markdown, into an Area or beneath a Page or Folder, from the Area screen or the Entry menu. An Export followed by an import gives the same tree, content, Tags and Attachments; files that do not come across are listed in a report instead of failing the import.
- **Ready-built binaries.** Each Release now has Turtle as one file for Linux on x86-64 and ARM64, statically linked so it runs on any distribution, and for macOS on Apple silicon, with `SHA256SUMS` to check the downloads against.
- **Turtle names its Release.** The account menu shows the version at its foot, linked to these notes; `turtle --version` prints it, and so does the first line Turtle logs.
- **Recently edited.** The start screen lists the Pages edited last, by anyone, among those the person can read.
- **Remove an Attachment.** Writers can remove a single Attachment from a Page, in the Attachments list, through the API and through MCP.
- **Find Pages by their Attachments.** Search now covers the file names of Attachments and highlights the matching file name in the result.

## Changed

- **Failed sign-ins are limited.** Signing in, accepting an invitation and setting a new password through a reset link are refused for 15 minutes after five failed attempts with one email address, or twenty from one client address.
- **One search everywhere.** The search sits at the top of the sidebar on every screen and opens with Cmd+K (Ctrl+K) or /. A switch above the results widens it from the Area to every Area.
- **A calmer interface.** Each screen has one main action, with the rest in a More menu. Every Area has a mark, the Personal Area sits apart from the shared ones, and one sage accent shows where you are. The Quick Note no longer needs a title.

## Fixed

- **Failed mail no longer locks people out.** When a password reset mail cannot be sent, asking again sends a new one at once instead of after five minutes. When an invitation or reset link an Admin creates cannot be mailed, Turtle returns the link to pass on, and the Members screen says so.
- **Large imports.** A ZIP up to `TURTLE_MAX_IMPORT_MB` (200 MB by default) can be imported, apart from the smaller limit every other request keeps.
- The toolbar no longer throws an error after a Quick Note is saved.

## Updating

Turtle rebuilds its search index once when it first starts, so that file names of Attachments are found; the rest of the data directory stays as it is. Nothing has to be done by hand, but two new settings may matter:

- Behind a reverse proxy, set `TURTLE_CLIENT_ADDRESS_HEADER` to the header that carries the client's address, such as `X-Forwarded-For`. Without it, everyone behind the proxy counts as one client when Turtle counts failed sign-ins.
- `TURTLE_MAX_IMPORT_MB` sets the largest ZIP that can be imported. A reverse proxy in front of Turtle has to accept requests that large too.

Keep a backup of the data directory before you update.
