Turtle 0.1.0 is an early preview: the first version to try, not yet one to run your team's documentation on. Until 1.0, the data format and the API may change between versions. Turtle brings an existing data directory up to date when it starts, but keep a backup before each update.

## What Turtle can do

- **Write together, live.** Several people edit a Page at the same time and see each other's changes as they type. Pages have headings, lists, task lists, callouts, tables, code, images, Attachments, Page links, Mentions of Members and Guests, and a Status to mark progress.
- **Areas, Pages and Folders.** Each Area holds a tree of Pages and Folders that can be reordered and moved. Every Member also has a Personal Area that only they see, and can jot down Quick Notes from the start screen.
- **Find things.** Search covers titles and content, tolerates typos and never shows what the searcher may not read. Pages can be tagged and found by Tag.
- **Versions and the Trash.** Every save is a Version that can be compared and restored. Deleted Pages, Folders and Areas go to the Trash first.
- **People and access.** Invite Members by link or, with SMTP set up, by mail. Members with the Admin Role on an Area give Roles there. Every Member and Guest has a Profile with an optional picture.
- **Agents as co-authors.** Claude and other MCP clients connect through OAuth or a Token at `/mcp` and read and write Pages as Markdown. A Token never has more access than its Member and can be limited to reading and to chosen Areas. What an Agent changes shows under its Member's name, such as "Ada Example via Claude". Standalone Agents get their own name, Tokens and Roles.
- **Your writing stays yours.** Every Page reads and writes as Markdown. An Area or Subtree exports as a ZIP of Markdown files with its Attachments, or as a PDF in a PDF Style with your own fonts and logo.
- **One binary, one data directory.** No database server and no outside services. Run it with `docker compose up -d`, or build it from source.

## What is still missing

- **Import**, from Markdown files or from Confluence.
- **A German interface.** Turtle speaks English only.
- **Recovering from failed mail.** When a password reset mail cannot be sent, the Member cannot ask for another for five minutes.
- **Rate limiting** for signing in and for single-use links. Put Turtle behind a reverse proxy that limits them before opening it to the internet.
- **Ready-built binaries.** For now Turtle comes as the container image `ghcr.io/jeremieconstant/turtle:0.1.0` or is built from source.
